Neon Coast Cover Studio — an offline web app that turns your photos and a caption into GTA-style cover art: multi-panel poster layouts, bold caption lettering, Vice City sunset and neon colour grades, per-panel crop and positioning, and PNG export at 1080×1080, 1080×1350 and 1920×1080. Fully offline; no Rockstar logo, artwork or fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
